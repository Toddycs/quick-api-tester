# 🌐 API Tester Web App

Uma ferramenta web responsiva e moderna para testar APIs, com suporte a histórico e interface amigável — inspirada no Postman!

## 🚀 Demonstração

🔗 Acesse o projeto online: [https://quick-api-tester.netlify.app](https://quick-api-tester.netlify.app)

## ✨ Funcionalidades

* Envio de requisições `GET`, `POST`, `PUT`, `DELETE`, etc.
* Inserção de headers customizados
* Corpo da requisição personalizável (JSON, texto, etc.)
* Histórico de requisições com navegação rápida
* Visual moderno com suporte a tema **claro** e **escuro**
* Botão de copiar a resposta com um clique
* Footer fixo com links para redes sociais

## 💪 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* jQuery
* Font Awesome (ícones)

## 📦 Como usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/toddycs/quick-api-tester.git
   ```

2. Abra o arquivo `index.html` no navegador.

> Não é necessário back-end para esse projeto. Tudo funciona no lado do cliente!

## 🥚 Exemplos de uso

* Teste endpoints RESTful rapidamente
* Envie tokens de autenticação nos headers
* Visualize e copie respostas de forma prática

## 📱 Responsivo

Compatível com celulares, tablets e desktops.
